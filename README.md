One deadpan weather line for a city that does not exist. The forecast
is absurd — a light dusting of frogs on the northern bypass — but it is
delivered exactly the way a real TV meteorologist would read it off the
map: concrete numbers, a concrete place, and a flat closing tag that
treats the frogs as ordinary data.

> Tonight in Grindlewick: clear skies, minus 2 degrees, and a light
> dusting of frogs on the northern bypass, clearing by morning, as
> frogs do.

## Why this line

One joke, held all the way through: the frogs are never winked at,
they are reported as ordinary weather data — "a light dusting",
"clearing by morning", the flat tag "as frogs do". The rest of the
line is straight broadcast: a named (invented) city, a time of day,
two concrete numbers (minus 2 degrees), a concrete place (the northern
bypass). Absurd, but nothing in the delivery admits it.

## Run it

```sh
python3 main.py
```

The program writes the single forecast line (140 characters, UTF-8, no
trailing newline) to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to
point it somewhere else for a local test run. Python 3.13 standard
library only; the output is deterministic — two runs produce the same
bytes.
